# ⚔️ KaratioCombat

**KaratioCombat** is a Minecraft plugin that provides a simple and effective **Combat Log / Anti-Logout system**.
The plugin prevents players from unfairly escaping PvP combat by disconnecting from the server.

---

## 📖 About
KaratioCombat is a **Combat Logging prevention plugin** for Minecraft servers.
When a player enters combat, they are placed in **combat mode** for a specific amount of time.
If the player disconnects while still in combat, the plugin force death player.
This helps prevent players from escaping fights by simply leaving the server.

---

## ✨ Features
* ⚔️ Combat tagging system
* ⏱️ Configurable combat duration
* 💀 Death when player logout

---

## 📦 Installation
1. Download the latest version of **KaratioCombat**.
2. Put the `.jar` file into your server's `plugins` folder.
3. Restart your Minecraft server.
4. Configure the plugin inside:

```text
plugins/KaratioCombat/
```
